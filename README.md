# 蔚蓝星球知识库

面向微信小游戏玩家的活动、英雄、武器、国王幻形、城墙与坐骑查询。

站点：https://anthonyyangxunyangxun-star.github.io/WLXQ-KLB/

- 活动：列表检索、分类筛选、共用日期轴排期、逐期奖励、攻略与游戏截图。冲刺按同类活动分别计次，排名奖单分第1—4期与第5期起，独立列出五档名次；轮次完成奖的四轮、五轮版本分别展示。
- 英雄：从常见到神话，支持品质、职业、定位和关键词筛选；详情包含简介、升级消耗、等级技能、局内词条、专属图腾与攻略视频。白蛇单独标记为赛季预告。
- 局内词条：具体描述分别保留伤害、数量、概率、持续时间等数值；同名变体分开，未取得的描述不推算。游戏词条截图可展开查看。
- 武器、国王幻形、城墙、坐骑：独立列表与筛选，详情包含简介、等级效果、兑换建议视频及界面截图。

开服天数和活动状态随上海日期计算。未取得的资料保留简短提示；预计日期、历史奖励与当前内容分别标记。收录资料不代表游戏完整清单。

发布文件为`index.html`、`data.json`、`assets/`与`.nojekyll`。GitHub Pages使用`main`分支根目录。
