# 蔚蓝星球知识库

面向微信小游戏玩家的英雄与活动查询。

站点：https://anthonyyangxunyangxun-star.github.io/WLXQ-KLB/

- 英雄：从常见到神话，支持品质、职业、定位和关键词筛选；详情介绍基础技能、升级消耗、等级技能、局内词条、专属图腾与攻略视频。白蛇单独标记为赛季预告。
- 活动：列表检索、分类筛选、共用日期轴排期、活动详情、逐期奖励和游戏截图。
- 国王皮肤、幻形、城墙、武器预留查询入口。

开服天数和活动状态随上海日期计算。未取得的资料保留简短提示；预计日期、历史奖励与当前内容分别标记。

发布文件为 `index.html`、`data.json`、`assets/` 与 `.nojekyll`。GitHub Pages 使用 `main` 分支根目录。
